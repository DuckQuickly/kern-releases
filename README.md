# KERN — beta downloads

### ⬇️ Download: **https://duckquickly.github.io/kern-releases**

The download page links the latest macOS build. No source code is hosted here.

## Manual download

Pick the latest asset from [Releases](https://github.com/DuckQuickly/kern-releases/releases):

- **macOS** — `KERN-macOS-<version>.dmg`: open it and drag **KERN** to **Applications**. The beta is not notarized, so macOS warns on first launch: open **System Settings → Privacy & Security** and choose **Open Anyway** next to KERN.

Each download has a matching `.sha256` checksum file. In-app updates are additionally verified with an owner signature (`.sig`).

Your contacts, notes, and settings live outside the app and survive updates — just install the newer build.

KERN is macOS only. Windows builds were discontinued on 2026-10-20; earlier Windows releases stay listed, but an installed Windows copy no longer receives updates.
