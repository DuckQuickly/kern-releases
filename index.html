Installing on macOS ›
  1. Open the downloaded .dmg.
  2. Drag KERN onto the Applications folder.
  3. Open KERN normally. Published builds are signed with a Developer ID and notarized by Apple. If macOS shows a warning anyway, do not open it and tell the owner.
  4. After that, KERN updates itself; your contacts, notes, and settings live outside the app and carry over.
Installing on Windows ›
  1. Run the downloaded .exe.
  2. Windows will say the publisher is unknown, because this beta installer is not code-signed. If the owner has not approved you for the Windows beta, do not install it.
  3. Your data is stored in your user profile and survives updates — just run the newer installer.
